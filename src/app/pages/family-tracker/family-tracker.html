How consent works here

01

You generate a private link for one family member — nothing is shared yet.

02

They open it on their own phone and see exactly who's asking and why, before anything happens.

03

If they tap Allow, the browser's native location prompt appears — their choice, on their device.

04

Their location streams to this dashboard, and they can stop sharing at any time.

Demo note: this runs entirely in your browser's local storage, so the live hand-off only works when both of you use this same browser/device. A production version would move member records to a backend (e.g. ASP.NET Core Web API + SignalR) so it works securely across devices.
